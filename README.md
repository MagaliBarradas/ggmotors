# GG Motors

Website institucional da GG Motors, oficina automóvel em Oliveira de Azeméis.

## Tecnologias

- React e TypeScript
- TanStack Start e TanStack Router
- Vite e Tailwind CSS

## Desenvolvimento

Instale o [Bun](https://bun.sh/) e execute:

```sh
bun install
bun run dev
```

## Comandos

```sh
bun run build
bun run preview
bun run lint
```
