# GG Motors

Website institucional da GG Motors, oficina automóvel em Oliveira de Azeméis.

## Estrutura

- `index.html` — conteúdo e estrutura do site.
- `css/styles.css` — apresentação e regras responsivas.
- `js/main.js` — menu móvel, animações e galeria.
- `assets/images/` e `assets/video/` — recursos locais do site.

O site utiliza HTML, CSS e JavaScript nativos, sem frameworks, dependências ou etapa de compilação. Abra `index.html` num navegador para o visualizar. Cada alteração guardada nos ficheiros desta pasta será publicada no GitHub Pages após ser enviada para a branch `main`.
